# TaskFlow

TaskFlow is a focused task management dashboard for capturing, tracking, and completing the work that matters. It is intentionally scoped as a clean baseline for future improvements.

## Technology stack

- React + TypeScript
- Vite
- CSS
- Vitest and React Testing Library

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

## Tests

```bash
npm test
```

## Production build

```bash
npm run build
```
